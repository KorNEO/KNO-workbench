# 신어 집필(M5) 워크벤치 개편 설계

작성일: 2026-08-25 · 대상: `KNO-workbench` (prod) · 상태: 초안(레이아웃 검토 중)

근거 문서: `workbench_reference/신어2022_집필 지침.pdf`, `workbench_reference/신어 형태부 오류 유형 및 집필 시 유의 사항.docx`

## 목적

2024 집필 검토에서 반복된 형태부 오류(표기 기호·품사·원어 기호·차용 판정·어종 층위 불일치)를
입력 단계에서 막는다. 조어법 열 신설, 단계별 활성화(체인), 형태부/의미부 분리 작업,
조어법–형태부 정합성 자동 점검(저장 차단), 작업자↔검수자 양방향 변경 하이라이트, LLM 참고값 복사.

## 결정 사항

| 항목 | 결정 |
|---|---|
| LLM 참고 필드 | 8개: 색인표제어·조어법·품사·일상어/전문어·전문 분야·의미 범주·뜻풀이·용례 (컬럼명 잠정 `LLM …`, M5 출력 스키마 확정 시 맞춤). 원어·어종은 LLM 제외 |
| LLM 값 사용 | 상단 "LLM 생성 결과" 박스, 값마다 "복사하기"(1차 작업 필드로) + 맨 아래 "전체 복사하기"(순서대로, 체인 따라감). 대상 필드 비활성이면 버튼도 비활성. 2차 검수 폼에는 복사 없음 |
| 조어법 | 연구자 입력 필드 신설. 값: 생성/차용/합성/파생/혼성/축약 |
| 부(部) 분리 | 형태부 = 주석류(단어/구·조어법·품사·일상어/전문어·전문 분야·색인표제어·등재표제어·고유어·원어·어종 표시·어원·의미 영역·집필 메모) / 의미부 = 뜻풀이·용례(작성례)·참고 용례(인용례)·참고 용례 URL·X년 Y월 신어·집필 메모 |
| 게이트 | **프로젝트 단위**. 프로젝트 `단계`(형태부/의미부)를 관리자가 전환. 형태부 단계: 의미부 폼 전체 비활성. 의미부 단계: 형태부 읽기 전용(검수자만 수정) |
| 형태부 입력 순서(체인) | 단어/구 → 조어법 → 품사(단어만, 기본 「명사」) → 일상어/전문어(구: 일상어→「구」 자동, 전문어→품사 없음) → 전문 분야(전문어만) → 등재표제어(색인표제어 자동) → 고유어 체크·원어 → 어종 표시 → 어원 → 의미 영역. 메모는 항상 활성 |
| 의미부 | 체인 없음, 전부 개방. 형식 점검만 |
| 고유어 | "고유어" 체크 → 원어·어원 비활성(1차·2차 모두), 어종 `고` 프리필(수정 가능) |
| 색인표제어 | 등재표제어에서 `-`·`^` 제거하여 자동 생성. 목록 내 같은 색인표제어가 있으면 순서대로 어깨 번호 01·02 자동 부여. **그 외 자동 생성 없음** |
| 혐오 표현 | 판별 `2차 혐오 표현 여부`=Y → 뜻풀이 프리필 끝에 "차별 및 비하하는 의미가 포함되어 있으므로 사용에 주의가 필요하다." 자동 삽입. 저장 시 문구 없으면 오류 |
| 1차/2차 저장 | **전 입력 필드를 1차/2차 쌍으로 저장**(`1차 조어법`/`2차 조어법` …). 최종값 = 2차 있으면 2차, 없으면 1차 |
| 양방향 하이라이트 | 2차 폼: 1차 대비 변경분 하이라이트 / 1차 폼: 2차 저장 후 검수자가 고친 필드 하이라이트 + 검수자 값 표시 |
| 2차 폼 | 값이 차 있으므로 체인 없이 전부 활성. 저장 시 동일 점검 |
| 저장 전 확인 창 | 해당 부의 전 필드 값 + 점검 결과를 모달로 보여주고 확인 후 저장 |
| 점검 강도 | 오류 = 저장 차단(프론트 + 서버 이중). 고유명 관련 판단(언어명 생략·대문자)은 자동 점검 없이 작업자에게 맡김 |

## 1. 데이터 스키마 (집필 프로젝트 시트)

- 관리: `ID`·`신어 후보`·`작업자`·`검수자`·`형태부 주차`·`의미부 주차`·`작업 구분`·
  `형태부 상태`·`의미부 상태`(미작업/1차완료/2차완료)·`형태부 1차 일시`·`형태부 2차 일시`·`의미부 1차 일시`·`의미부 2차 일시`
- 판별 참조: `출처`·`추출 시기`·`2차 판별`·`2차 고유명 여부`·`2차 혐오 표현 여부`·`용례`·`용례 일자`·`용례 URL`·`검색 URL` (탑재 시 확정)
- LLM 참고(잠정): `LLM 색인표제어`·`LLM 조어법`·`LLM 품사`·`LLM 일상어/전문어`·`LLM 전문 분야`·`LLM 의미 범주`·`LLM 뜻풀이`·`LLM 용례`
- 형태부 입력(×1차/2차): 단어/구·조어법·품사·일상어/전문어·전문 분야·등재표제어·색인표제어·고유어·원어·어종 표시·어원·의미 영역·집필 메모(형태부)
- 의미부 입력(×1차/2차): 뜻풀이·용례·참고 용례·참고 용례 URL·X년 Y월 신어·집필 메모(의미부)
- 검수 메모(형태부)·검수 메모(의미부) (2차만)
- 프로젝트 시트(`PROJ_HEADERS`)에 `단계` 컬럼 추가(형태부/의미부, 기본 형태부)
- 컬럼은 헤더명 기준 접근, 없으면 자동 추가(기존 방식)

## 2. 백엔드 API (Code.gs)

- `saveWrite(token, {row_id, part('형태부'|'의미부'), stage(1|2), fields, op_id})`
  - 프로젝트 `단계`와 `part` 불일치 → 거부. 권한 `assertCanEditStage_` 유지
  - `fields`를 `{stage}차 {field}` 컬럼에 기록(해당 부 화이트리스트만)
  - 서버 측 점검(§4) 실패 → throw(저장 차단)
  - `{part} 상태`·`{part} {stage}차 일시` 갱신, 변경로그
- `setProjectPhase(token, projectId, phase)` — 관리자 전용. `getProjects` 응답에 `phase` 포함
- `addWriteItem`/`deleteWriteItem`/`getItems(full)`는 컬럼 확장만

## 3. 프론트 화면 (index.html `renderWriteDetail`)

1. 표제어·메타(출처·출현 시점·작업자-검수자·주차·고유명/혐오 배지)
2. LLM 생성 결과 박스(복사하기·전체 복사하기). 뜻풀이 변경 이력은 맨 아래. 필드 라벨 옆 ? = 주요 지침(문구는 `FIELD_HELP`, 현재 '입력 필요')
3. **형태부 섹션 → 의미부 섹션** 세로 배치(탭 없음). 프로젝트 단계에 따라 잠금 표시
4. 각 섹션 안: 1차 작업(좌) | 2차 검수(우). 1차 형태부 폼은 체인 활성화, 2차는 전부 활성. 단어/구·일상어/전문어·조어법·품사(명사·부사·동사·형용사·감탄사+직접 입력)는 버튼식, 전문 분야·의미 영역·품사 직접 입력은 자동완성(↑↓ Enter). 짧은 필드는 2열
5. 저장 버튼 → 확인 모달(전 필드 + 점검 결과) → 저장 큐

체인 규칙(1차 형태부): 각 단계는 직전 적용 단계가 입력되면 활성. 건너뛰는 단계(구의 품사, 일상어의 전문 분야, 고유어의 원어·어원)는 완료로 간주. 어원은 선택 입력이라 의미 영역을 막지 않음.

## 4. 자동 점검 (전부 오류 = 저장 차단)

형태부:
1. 등재표제어에 한글·`-`·`^`·`·`·공백·번호 외 문자(로마자 포함)
2. `^`와 공백 동시 사용
3. 단어인데 공백/`^` · 구인데 `-`
4. 구+일상어: 공백 없음 / 품사≠「구」 / 전문 분야 있음
5. 구+전문어: `^` 없음 / 품사 있음 / 전문 분야 없음
6. 단어: 품사 빈칸·「구」 / 전문어인데 전문 분야 없음 / 일상어인데 전문 분야 있음
7. `-` 2개 이상
8. 조어법=혼성·축약인데 `-` 있음
9. 조어법=차용인데 원어에 `▼`
10. 조어법=차용인데 어원 빈칸
11. 원어에 허용 외 문자(`^`·`-`·`+` 등). 허용: 한글·한자·로마자·`←▼▽<>[]/`·공백
12. 고유어 체크인데 원어·어원 있음 / 미체크인데 원어 빈칸
13. 고유어 체크인데 어종에 `고` 외 토큰
14. 어종에 허용 토큰(고·한·언어 약어)·기호(`+ _ ^ ( )`) 외 문자
15. 어종 기호(`+`/`_`/`^`) 열이 등재표제어(`-`/공백/`^`) 열과 불일치
16. 어종 괄호 안이 동일 어종만(`(고+고)`)
17. 품사·전문 분야·의미 영역 값이 허용 목록/괄호 형식 밖
18. 어깨 번호가 있는데 목록 내 동형어 없음

의미부:
19. 뜻풀이 빈칸
21. X년 Y월 신어가 `【OOOO년 OO월 신어】` 형식이 아님
22. 뜻풀이·용례에 괄호 밖 로마자
23. 혐오 표현 여부=Y인데 주의 문구 없음

## 5. 미리보기·개발 방식

- 로컬 정적 서버(5002)에서 `index.html`을 열고 F5로 확인. `?demo=write[&phase=의미부]` 는 백엔드 없이 샘플 항목으로 레이아웃만 렌더하는 개발용 모드(저장 안 됨).
- 백엔드는 화면 확정 후 일괄 수정·배포.
