## 남은 작업(우선순위 순)
1. **물음표 도움말 문구** — `index.html`의 `FIELD_HELP` 16개가 전부 "주요 지침 입력 필요". 필드별 필수 지침 문장을 사용자가 정하면 그대로 넣기
2. **테스트 피드백 반영** — 이수진·백미경·안진산 사용 후 나온 수정 사항
3. **923건 본 프로젝트 탑재** — "신어 집필 작업"(유형 `집필`)에 CSV 업로드. 배분 파일(`…_계열_배분.xlsx`, 다른 세션에서 작업 중)의 집필_작업자/검수자/형태부_주차/뜻풀이_주차를 CSV의 작업자/검수자/형태부 주차/의미부 주차로 매핑, 판별 담당자는 판별 작업자/판별 검수자 컬럼으로
4. **M5 LLM 컬럼명 확정** — 현재 잠정 `LLM 색인표제어·조어법·품사·일상어/전문어·전문 분야·의미 범주·뜻풀이·용례`. M5 출력이 확정되면 `LLM_MAP`(프론트)·`WRITE_LLM`(백엔드)·양식 CSV 3곳 동시 수정
5. LLM 의미 범주에 15개 밖 값(예: 〔정보ㆍ기술〕)이 있음 → M5 쪽에서 15개로 제한하거나, 복사 시 비워지는 현재 동작 유지
6. 의미부 단계 실사용 검증(형태부 단계에서 복사해 둔 뜻풀이·용례가 의미부 전환 후 그대로 보이는지)

## 결정 사항 요약(다시 묻지 말 것)
- 형태부 체인: 단어/구 → 조어법(단어만) → 품사(단어만, 기본 「명」, 대표 음절) → 일상어/전문어 → 등재표제어 → 원어(고유어 체크 시 원어·어원 비활성) → 어종 표시 → 어원 → 전문 분야(전문어만) → 의미 영역. 의미부 11~15는 전부 개방, X년 Y월 신어는 추출 시기에서 자동
- 구 선택 시 조어법·품사 건너뜀(일상어→「구」, 전문어→품사 없음)
- 점검은 필수 형식 오류만(문장형 문구), 저장 차단은 프론트+서버 이중. 목록 값(전문 분야·의미 영역·품사 직접 입력)은 자동완성으로 강제
- 기호는 `집필_시_특수기호.txt` 기준(가운뎃점 ㆍ U+318D). 입력 시 자동 치환
- 화면: 이모지 금지(판별·집필 카드 🧭 ✍️와 다크 🌙만 예외), 엠대시 금지, 임의 안내 문구 금지, 빈 값 "-", 확인 창은 uiConfirm으로 통일
- 집필 사례 패널: 오른쪽 고정, 기본 접힘, 2020-2024(KNO_DATASET) → 2025(형태부 저장된 항목만) 순, 매칭 = 포함 > 접미 ≥2자 > 접두 ≥2자
- 단계 전환: 홈 "집필 단계" 카드의 형태부/의미부 토글(관리자), 되돌리기 허용
