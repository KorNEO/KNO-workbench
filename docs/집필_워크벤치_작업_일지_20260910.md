## 바뀐 동작(원어 행)
- 모든 행이 같은 구조: `[⋮ 손잡이 | 성분 칸(편집 가능) · 원어 칸 · 우리말샘 · × ]` + 둘째 줄(언어명·▼▽←·고유명).
  - 자동 생성 행: 등재표제어의 `-`·공백·`^` 조각이 성분 칸에 미리 들어감. 성분 칸을 직접 고칠 수 있고, 어느 행이든 `×`로 삭제 가능.
  - `+` 행: 맨 아래에 성분 칸이 빈 행으로 생성. 손잡이를 끌어 원하는 행 사이에 놓을 수 있음(위/아래 반쪽에 따라 삽입선 표시).
- 성분 묶음 규칙(어종 표시 계산): 성분 칸이 채워진 행이 새 성분을 시작하고, 빈 행(`└`)은 바로 위 성분에 이어짐. 첫 행은 비어 있어도 성분 시작.
- 성분 사이 기호: 성분 칸이 등재표제어 조각과 그대로 일치하면 그 조각의 기호. 아니면 등재표제어에서 `앞 성분+기호+뒤 성분`을 찾고, 없으면 `-`(어종에서는 `+`).
- 손댄 행(성분 수정·추가·삭제·이동 → `data-touched`)은 등재표제어를 다시 고쳐도 다시 만들지 않음(행이 정본). 손대지 않은 행은 기존처럼 조각 변화에 맞춰 자동 재생성.
- 원어·어종은 행이 바뀔 때마다(입력·드래그·삭제) 현재 행에서 즉시 재조립. 최종 원어 칸 역반영은 기존과 같이 행 순서대로.
- 잠금(원어 칸 비활성)이면 손잡이·성분 칸·`×`도 함께 잠김.
- 성분이 하나만 남으면 외국어를 `+`로 전부 나열하는 기존 규칙(칩플레이션 영+영) 유지.
