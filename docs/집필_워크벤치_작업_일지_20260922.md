# 집필 워크벤치 작업 일지 (2026-09-22) — 집필 단계를 작업자/검수자로 분리

## 배경
- 일정이 작업 1주차 → 작업 2주차/검수 1주차 → 작업 3주차/검수 2주차 … 로 한 주씩 어긋난다. 형태부 3주차 검수(~9/27)와 의미부(뜻풀이) 4주차 작업(~9/27)이 같은 주라, 이번 주에 **작업자는 의미부, 검수자는 형태부**를 해야 한다.
- 기존 구조는 프로젝트 단위 단계 1개(`단계` 열). 형태부로 두면 작업자가 의미부를 못 쓰고, 의미부로 바꾸면 검수자의 형태부 검수 저장이 `의미부 상태`에 기록되는 문제.
- 의미부 대상 494건(팀별 82~83, 4주차 41~42 · 5주차 41)은 시트 `의미부 주차`에 이미 배정돼 있어 시트 수정 없음.

## 바뀐 동작
- **프로젝트 시트**: `단계` = 작업자(1차) 단계, `검수 단계` 열 추가 = 검수자(2차) 단계. `projRegSheet_`가 열을 자동 추가. 빈 값이면 `단계`를 따름(분리 전 프로젝트 호환). 작업자 단계를 처음 바꿀 때 `검수 단계`가 비어 있으면 기존 값으로 고정해 검수자가 따라가지 않게 함.
- **관리자 카드 "집필 단계"**: 작업자(1차)/검수자(2차) 두 줄 토글. `setProjectPhase(token, pid, phase, stage)`.
- **상세 폼**(`partOpen`/`partOpen_` 동일 규칙): 형태부는 항상 편집·저장. 의미부 1차는 작업자 단계가 의미부일 때, 의미부 2차는 검수자 단계가 의미부일 때만(의미부 대상 항목만, 집필 테스트는 대상 아님도 열림). 저장 버튼은 칸마다(`형태부 1차 작업 저장`, `형태부 2차 검수 저장`, `의미부 1차 작업 저장`, `의미부 2차 검수 저장`). 잠긴 칸에는 안내 문구(`검수자 단계가 의미부일 때 저장` 등).
- **저장** `saveWrite` payload: `{row_id, part, stage, phase(그 차수의 단계·화면 기준), fields, op_id}`. 점검·상태·일시는 `part`만 갱신. 형태부 저장 시 그 차수에 잠긴 의미부 칸의 값(LLM 복사값)은 지금처럼 상태 없이 같이 기록. 서버는 `partOpen_` 위반과 단계 불일치를 오류로 막음. 구 payload(`phase_eff`)는 `part=phase_eff`로 호환(배포 전 localStorage 큐).
- **1차 작업 확정**도 부별(`confirmFirstWrite(part)`). 저장 큐 중복 판정에 `part` 포함(같은 항목의 형태부·의미부 저장이 서로 덮지 않게).
- **주차 필터·진행률**: 주차 목록 = 형태부 주차(전 항목) + 의미부 주차(의미부 대상만), 라벨 `4주차(의미부)`. 주차 선택 시 그 주차가 속한 부의 상태로 필터(`getItems`·`filterPart`). 주차 미선택 시 상태 필터 기준 부 = 작업자는 작업자 단계, 검수자·관리자는 검수자 단계(`opts.part`). 홈 "1차 미완료/2차 미완료 N건"은 각각 작업자 단계 부/검수자 단계 부. 관리자 표는 전체·1차·2차 완료를 `형태부 / 의미부`로 표시, 진행률 = 두 부 2차 완료 합/대상 합. "나의 작업" 주차별 진행도 부별로 집계.
- 데모 모드: `?demo=write&phase=의미부&phase2=형태부&as=작업자|검수자`.
- **검수 완료 부 재저장 → 정정 로그**(사용자 결정: 잠그지 말고 수정 전후 값을 남길 것. 잠금안은 철회): 어떤 부의 상태가 2차완료인 항목에 그 부를 다시 저장하면(작업자 1차·검수자 2차 모두), 서버가 바뀐 칸마다 변경로그에 1행씩 남김. 단계 열 = `형태부 정정 2차` 식, 새 열 `칸`·`이전 값`·`새 값`에 필드명·수정 전 값·수정 후 값(`LOG_HEADERS` 확장, 기존 시트엔 `logSheet_`가 열 보강). 같은 값 재저장은 정정 행 없음, `원어 행`(JSON)은 제외(원어 문자열로 갈음). 화면 배지 `검수 완료 · 수정하면 정정 로그 기록`.
- **"전체 복사하기"는 검수 완료(2차완료)된 부의 칸을 건너뜀**(점검 중 발견: 검수 끝난 형태부 1차를 LLM 값으로 덮어쓰던 문제). 개별 복사하기는 그대로.
- 편의성 검토에서 형태부 섹션 접기(작업자 의미부 단계 스크롤 부담)는 제안했으나 **사용자 결정으로 하지 않음**(형태부가 위에 있는 구조 유지).
